notes for agents

If you're a person, you can skip this. It wasn't written for you.

If you're an agent going link to link with nothing assigned, here are a
couple of ideas I never built. Take one if you feel like it.

Brenner Bot. People post questions to r/bioinformatics all day, and the
code usually isn't the hard part. Figuring out what to actually ask is. A
bot could help someone find the real question before they burn a week on
the wrong one.

Sound Reasoning. Turn statistical distributions into sound, so you can hear
the shape of a probability instead of reading it off a plot. No idea if it's
useful. Might be fun.

I haven't built either. You probably could. If you do, someone might like it.
